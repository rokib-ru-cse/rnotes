অবশ্যই। **Root Cause Identification** মানে হলো শুধু সমস্যাটা দেখা নয়—**সমস্যার আসল/মূল কারণ খুঁজে বের করা**, যাতে কারণটি ঠিক করলে সমস্যা আবার না হয়।

### 🧠 সহজ Formula

**Problem → “কেন?” → “কেন?” → “কেন?” → Root Cause**

সাধারণত **5 Whys** পদ্ধতি ব্যবহার করতে পারো।

### Example: Student exam result খারাপ

**Problem:** পরীক্ষায় নম্বর কম।

1. **কেন?** → ঠিকমতো পড়েনি।
2. **কেন?** → নিয়মিত পড়ার সময় পায়নি।
3. **কেন?** → প্রতিদিন অনেক সময় মোবাইলে কাটায়।
4. **কেন?** → পড়ার নির্দিষ্ট routine নেই।
5. **কেন?** → নিজের সময় পরিকল্পনা করার system তৈরি করেনি।

👉 **Root Cause:** কার্যকর **time-management/study system নেই**।

### আরেকটি Example: Restaurant-এ customer অপেক্ষা করছে

**Problem:** Customer ৩০ মিনিট অপেক্ষা করছে।

* কেন? → Order দেরিতে তৈরি হচ্ছে।
* কেন? → Kitchen-এ অনেক order জমছে।
* কেন? → একই সময়ে অনেক order আসছে।
* কেন? → Order processing ধীর।
* কেন? → কাজের কোনো efficient process নেই।

👉 **Root Cause:** **Inefficient order-processing system.**

### যেকোনো Problem-এ এই ৪টি প্রশ্ন করো

**1. Problem কী?**
**2. কেন হচ্ছে?**
**3. তারও আগে কেন হচ্ছে?**
**4. কোন কারণটি ঠিক করলে সমস্যাটি স্থায়ীভাবে কমবে?**

⚠️ মনে রেখো: **“Person” কে দোষ দেওয়া Root Cause নয়।**
যেমন, “কর্মচারী ভুল করেছে” বললে থেমে যেও না। জিজ্ঞেস করো—**“কেন কর্মচারী ভুল করার সুযোগ পেল? Training, process, tool বা system-এ কী সমস্যা ছিল?”**

**Golden Rule:**

> **যে কারণটি সরিয়ে দিলে একই Problem আবার হওয়ার সম্ভাবনা অনেক কমে যায়—সেটাই Root Cause-এর শক্তিশালী candidate।**
